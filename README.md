# Student Management API (Backend)

A simple RESTful API built with Node.js and Express to manage student records. This application supports full CRUD operations (Create, Read, Update, Delete) using an in-memory data structure.

## 🚀 Features

* **Create:** Add new students to the system.
* **Read:** Retrieve a list of all students or details of a specific student.
* **Update:** Modify existing student details (partial updates supported).
* **Delete:** Remove a student from the system.
* **Architecture:** Backend-only application using REST principles.

## 📦 Installation & Setup

1.  **Clone the repository** (or download the files):
    ```bash
    git clone <your-repo-url>
    cd <your-project-folder>
    ```

2.  **Install dependencies:**
    ```bash
    npm i
    ```
## ▶️ Running the Application

Start the server using Node:
```bash
npm run dev
```
